## About Me

I'm an iOS developer and CS graduate with hands-on experience building and shipping real-world applications. I'm currently at **[Swiggy](https://www.swiggy.com)**, working on production features for Dineout, building reusable UI components, and contributing to the migration from UIKit to SwiftUI.

At **Intern Labs**, I independently built a matrimonial matchmaking app using Swift, SwiftUI, and Firebase — implementing authentication, onboarding, profiles, and real-time data.

Outside of internships, I like building products from scratch. **Gito**, one of my recent projects, is an offline-first notes app built with SwiftUI and SwiftData, supporting media attachments, drawing, and speech-to-text.

I'm passionate about learning through building, sharpening my engineering fundamentals, and creating software that solves real problems.
